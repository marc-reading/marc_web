# Old design (archived)

This folder keeps the previous MARC website exactly as it was before the Kerala-themed redesign
(TemplateMo "Tiya Golf Club" Bootstrap template).

- Open `old-design/index.html` to view it.
- It has its own copy of the old CSS, JS and icon fonts in `old-design/static/`.
- Images are **not** duplicated: the pages load them from the shared `../static/images/` folder,
  so do not delete images from there while this archive is kept.
- Pages are marked `noindex, nofollow` so search engines ignore the archive if it is deployed.
- `event-details.html` and `event-listing.html` are unused template placeholder pages.
